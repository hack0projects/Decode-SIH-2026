## What is a Chemical Reaction?

A **chemical reaction** is a process in which substances (reactants) transform into new substances (products) with different chemical properties. This is different from a **physical change**, where no new substance is formed (e.g., melting ice — still water, just a different state).

### Signs that a Chemical Reaction has Occurred
1. Change in color
2. Formation of a precipitate (insoluble solid)
3. Evolution of a gas (bubbles)
4. Change in temperature (heat released or absorbed)
5. Change in state

---

## Writing a Chemical Equation

A **chemical equation** represents a reaction using chemical formulas.

```
Reactants  →  Products

Example: Magnesium + Oxygen → Magnesium oxide
         2Mg  +  O₂  →  2MgO
```

### Balancing Chemical Equations (very important skill)

The **Law of Conservation of Mass** states that mass can neither be created nor destroyed in a chemical reaction — so the number of atoms of each element must be equal on both sides of the equation.

**Example — Balancing:** Fe + H₂O → Fe₃O₄ + H₂

```
Step 1: Count atoms on both sides (unbalanced)
Left:  Fe=1, H=2, O=1
Right: Fe=3, O=4, H=2

Step 2: Balance Fe first
3Fe + H₂O → Fe₃O₄ + H₂

Step 3: Balance O (need 4 oxygen atoms, so 4 H₂O)
3Fe + 4H₂O → Fe₃O₄ + H₂

Step 4: Balance H (4H₂O gives 8 H atoms, so need 4H₂)
3Fe + 4H₂O → Fe₃O₄ + 4H₂

Final balanced equation: 3Fe + 4H₂O → Fe₃O₄ + 4H₂
```

## Types of Chemical Reactions

### 1. Combination Reaction
Two or more substances combine to form a single product.
```
A + B → AB

Example: CaO + H₂O → Ca(OH)₂
(Calcium oxide + Water → Calcium hydroxide, releases heat)
```

### 2. Decomposition Reaction
A single compound breaks down into two or more simpler substances. Often requires energy input (heat, light, or electricity).
```
AB → A + B

Example (thermal decomposition): CaCO₃ →(heat)→ CaO + CO₂
Example (electrolytic decomposition): 2H₂O →(electricity)→ 2H₂ + O₂
Example (photodecomposition): 2AgCl →(sunlight)→ 2Ag + Cl₂
```

### 3. Displacement Reaction
A more reactive element displaces a less reactive element from its compound.
```
A + BC → AC + B

Example: Fe + CuSO₄ → FeSO₄ + Cu
(Iron displaces copper because iron is more reactive)
```

### 4. Double Displacement Reaction
Two compounds exchange ions to form two new compounds, often producing a precipitate.
```
AB + CD → AD + CB

Example: Na₂SO₄ + BaCl₂ → BaSO₄↓ + 2NaCl
(BaSO₄ is an insoluble white precipitate)
```

### 5. Oxidation and Reduction (Redox Reactions)
- **Oxidation:** gain of oxygen OR loss of hydrogen OR loss of electrons.
- **Reduction:** loss of oxygen OR gain of hydrogen OR gain of electrons.

```
Example: CuO + H₂ → Cu + H₂O
Here, CuO loses oxygen (reduced to Cu), and H₂ gains oxygen (oxidized to H₂O)
This is a redox reaction — both oxidation and reduction happen simultaneously.
```

**Memory trick — "OIL RIG":** **O**xidation **I**s **L**oss (of electrons), **R**eduction **I**s **G**ain (of electrons).

## Effects of Oxidation in Daily Life

### Corrosion
When a metal is attacked by substances around it (moisture, acids), like iron rusting.
```
Rusting of Iron: 4Fe + 3O₂ + 2xH₂O → 2Fe₂O₃·xH₂O (hydrated iron oxide, i.e., rust)
```
Rusting requires **both air (oxygen) and moisture** — iron does not rust in dry air or in water without dissolved oxygen.

### Rancidity
When fats and oils in food get oxidized, causing bad smell and taste (e.g., stale chips). Prevented by:
- Adding antioxidants
- Storing food in airtight containers
- Refrigeration
- Packaging food in nitrogen gas (displaces oxygen)

## Worked Example

**Question:** Identify the type of reaction and balance: Zn + HCl → ZnCl₂ + H₂

**Solution:**
```
Type: Displacement reaction (Zn displaces H from HCl)

Balancing:
Left:  Zn=1, H=1, Cl=1
Right: Zn=1, Cl=2, H=2

Need 2 HCl to balance Cl, which also balances H:
Zn + 2HCl → ZnCl₂ + H₂  (balanced ✓)
```

## Common Mistakes Students Make
1. Forgetting to balance equations before identifying the reaction type — an unbalanced equation can lead to wrong conclusions about stoichiometry.
2. Confusing **decomposition** (one substance breaking into many) with **displacement** (one element replacing another in a compound) — these are structurally opposite processes.
3. Thinking oxidation only means "gaining oxygen" — students often forget the electron-transfer and hydrogen-loss definitions, which matter in more advanced redox questions.
4. Forgetting the physical state symbols (s, l, g, aq) or the precipitate arrow (↓) when writing complete chemical equations, which examiners specifically check for.
